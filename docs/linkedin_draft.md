# LinkedIn draft

For our Applied Machine Learning assignment, we compared on-site sensors with public weather for estimating a solar plant's hourly AC power, implementing the normal equation, batch gradient descent and ordered SGD directly in NumPy.

On the held-out daytime hours, the normal-equation model achieved an RMSE of 704.46 kW with on-site sensors, compared with 3,409.50 kW using public weather; we also built an interactive dashboard with synchronized sliders and typed inputs.

The public-weather location and timing checks remain unresolved, so we describe this as a historical plant-scale experiment, not a validated rooftop or live forecast.
